# Animation Skill for Claude Code

Reusable instructions for cinematic AI-animated story production.

## Install in a project

Clone this repository directly into the project's Claude Code skills directory:

```bash
mkdir -p .claude/skills
git clone https://github.com/yourquirey-gif/Animation-skill.git .claude/skills/animation-skill
```

The expected entry point is:

```
.claude/skills/animation-skill/SKILL.md
```

Restart or reopen Claude Code if the skill is not immediately discovered. Ask Claude Code to inspect and follow the animation-skill.

## What it covers

- Reference-video analysis and style guide creation
- Story breakdown and shot-by-shot storyboards
- Character and location bibles
- Character, prop, and environment continuity
- Real motion generation through video/3D providers
- Voice, dialogue, music, and subtitle synchronization
- FFmpeg assembly and export
- Shot-level and final quality control
- Provider verification, cost transparency, resumable jobs, and honest status reporting

## Important

This repository contains the reusable skill instructions and templates. It is not itself a hosted video-generation service and does not include paid provider API credentials. Actual video generation requires a configured compatible provider or a local 3D animation workflow.

Never treat a still-image slideshow with zoom effects as actual character animation.
