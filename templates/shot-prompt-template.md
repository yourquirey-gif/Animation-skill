## Subject and identity
Describe the character using the canonical Character Bible. Include stable face, hair, body proportions, clothing, accessories, and distinguishing traits. State which approved reference images must be used.

## Action
Describe ONE primary action with a clear beginning, middle, and end. Specify body movement, hand placement, gaze, expression, contact with props, direction, and speed.

## Environment
Describe the exact location using the Location Bible. Include spatial layout, ground plane, architecture, background objects, weather, time of day, and continuity with adjacent shots.

## Lighting and visual style
Specify key/fill/rim light, shadow direction, color palette, atmosphere, texture, and reference style.

## Motion instructions
State what moves, what remains stationary, movement direction, timing, and any environmental motion. Avoid contradictory simultaneous actions.

## Continuity constraints
List identity, wardrobe, prop state, screen direction, eyeline, location, lighting, and object positions that must remain consistent.

## Negative constraints
Exclude unwanted character redesign, wardrobe changes, extra limbs/fingers, fused hands, floating objects, incorrect tool grip, object penetration, broken geometry, text artifacts, flicker, morphing, and unrelated subjects.

## Acceptance criteria
Define what must be visibly correct for this shot to be accepted.
